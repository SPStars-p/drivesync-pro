Konfigurasi API

Agar file dari laptop Anda benar-benar bisa terunggah ke akun Google Drive milik Anda, masukkan **Google Client ID (OAuth 2.0)** Anda di bawah ini:

Cara Mendapatkan Client ID (Gratis):

  1. Buka Google Cloud Console.
  2. Buat Project Baru & Aktifkan Google Drive API.
  3. Pada menu OAuth consent screen, pilih External dan isi nama aplikasi Anda.
  4. Pada menu Credentials, klik Create Credentials → OAuth client ID.
  5. Pilih Tipe Web application, lalu masukkan URI asal Javascript browser Anda.
  6. Salin Client ID yang diberikan dan tempelkan di kotak atas!
